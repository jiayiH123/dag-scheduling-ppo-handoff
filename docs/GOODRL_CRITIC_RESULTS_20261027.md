# GOODRL思想迁移：三阶段critic训练对照（2026-10-27）

本轮是已知862条VAL上的单种子机制探索。改变训练用critic，部署仍为一次完整actor forward和一次确定性物理构造。没有TEST/OOD评估。

## 实际训练规模与共同设置

- 数据底库为17261条去重TRAIN配置、10000张底图；每臂实际使用同一2048条TRAIN配置，各采样一个完整方案，128次收集×16图。任务数20/40/80/120，资源池3/4/6。
- 每次收集有4遍actor优化、图minibatch8，通常共1024次actor优化；这里的4遍是当批16图，不是完整TRAIN的4个epoch。
- 共享BC起点C/HEFT0.8753856007519394；actor32612参数，输出(a,w,c_gap,c_wait)。硬预算、通信、容量、HEFT顺序、物理评分不变。
- 经典PPO：gamma1/lambda1，clip0.2、entropy0.001、actor Adam3e-5、critic Adam1e-3、gradclip1。无BC锚定/教师loss，无多候选部署取最优。
- 每阶段共享采样另256条TRAIN配置作为预热缓存，224拟合/32预热留出；warm臂额外做200次critic minibatch更新。报告额外计算，不声称等FLOPs。

## 审计和结果边界

- 预训练前12种任务数/池数组合：自身轨迹logprob误差小于5e-5，奖励和等于−C/HEFT；critic不向actor反传。图状态未来分配/时间扰动后，早期前缀输入和value一致。
- 每个VAL实例每个actor严格一次forward；每份方案通过原物理约束校验。所有评估节点、正负结果、最后检查点均保留。
- 增加更新后整批KL和固定BC参考KL。小单批KL不意味着累计BC漂移小；尚未隔离漂移的因果作用。
- 新cold控制与历史lambda1在VAL0/32相同，后续有差异；第一58批采样目标相同。新runner把value推理合批，FP32执行路径不同，不称逐位复现；主要使用新cold/warm配对。
- 图critic为本项目的两层消息传递＋小Attention适配，显式边时延、池通信、前缀预留和预算；不是原GOODRL GAT数值复现。wide作为参数量控制。
- first4/first16保持四遍actor minibatch排列一致；旧采样logprob固定，只有value更新组织、次数和优势刷新改变。
- 组件有既有方法先例，不直接作为原创贡献。单种子已知VAL探索、超过BC起点、超过BC续训和超过Teacher64是不同结论。
